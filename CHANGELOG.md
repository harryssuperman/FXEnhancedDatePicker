# Changelog

Notable changes to this project are documented in this file.

## [1.0.0]

### Added

- Modular Maven build with BOM, API, core, controls, animations, themes, and demo modules.
- JavaFX `EnhancedDatePicker` with a persistent selected-date summary and a panel for direct navigation across days, months, years, decades, centuries, and millennia.
- Pagination for year, decade, and century selection, plus automatic panel dismissal after selecting a day.
- Default and weekday-enabled themes, configurable date formatting, and resizable date and selection panels.
- `DatePickerConfiguration` for locale, font family, font size, text and accent colors, date format, panel dimensions, and custom translations.
- Built-in Spanish, English, and German UI translations.
- Unit tests for date selection, navigation, and configuration.

### Build

- Target Java 25 and JavaFX 25.
